## 1. 项目速览

- 路径：`G:\Code\Rust\Pek.RDB`；远程 `github.com/RemoteAll/Pek.RDB`，分支 `main`。
- 建仓：2026-10-31（空仓库起步）。
- 目标：一体化数据引擎（嵌入/网络双模、文件夹即数据库、Engine + Flux + KV + Pek.RCode Provider）。
- 设计唯一口径：`docs/架构设计.md`。
- **实现语言：Zig 0.17.0**，全部源码在 `spike-zig/`。
  根目录**不是** Rust 工程（历史与工作区里都没有 `src/*.rs`、也没有根 `Cargo.toml`）；
  Rust 只用于对照工具 `tools/bench-vs-sqlite/`。

## 2. 常用命令（构建 / 测试 / 回归）

```powershell
cd spike-zig
zig build test                        # 全部回归（当前 65 个用例）
zig build -Doptimize=ReleaseFast      # 基准必须用 ReleaseFast；默认是 Debug，慢到没有意义
zig build run-bench                   # 跑基准（输出 CSV 到 stdout）
$env:CARGO_TARGET_DIR='D:\cargo-target\pek-rdb-tools'
cargo build --release --manifest-path tools\bench-vs-sqlite\Cargo.toml   # SQLite 对照工具
```

- Zig 工具链：`zig version` 必须是 **0.17.0**。
- 依赖镜像：`tools/bench-vs-sqlite` 走 `.cargo/config.toml`（rsproxy sparse）；Zig 侧无第三方依赖。
- 0.17 硬变更（已实测）：`std.Io` 统一 IO、`std.Thread.Mutex` 已移除、
  `std.ArrayList` 为 unmanaged、`@backingInt`/`@fromBackingInt`、`@splat`。

## 4. 目录要点

| 路径 | 说明 |
|---|---|
| `spike-zig/src/codec.zig` | varint、CRC、行记录编解码（含块内前缀重建 `RecIter`）、分块 `KeyArena` |
| `spike-zig/src/skiplist.zig` | Arena SkipList memtable，排序 `(key ASC, seq DESC)` |
| `spike-zig/src/wal.zig` | 追加日志 + 组提交 + 撕裂尾截断恢复 |
| `spike-zig/src/segment.zig` | 不可变有序段（`.data` + `.idx`，mmap 读 + 稀疏索引 + Bloom + 块内前缀压缩） |
| `spike-zig/src/table.zig` | 表 CRUD / 扫描 / flush / compaction / 归并（`MergeIter`） |
| `spike-zig/src/engine.zig`、`catalog.zig`、`sql.zig`、`exec.zig`、`schema.zig` | SQL 层与目录 |
| `spike-zig/src/m0*.zig` | 极小资源档（M0：无 MMU / 固定池） |
| `spike-zig/src/main.zig`、`bench_*.zig` | 基准驱动（CSV 指标） |
| `tools/pairs-verdict.ps1` | 同批 min–max 区间重叠判定（区间重叠 = 测不出来，不是打平） |
| `tools/pairs-paired.ps1` | **交替配对**的逐轮比值 + 符号检验（N=7 时 7/7 才显著） |
| `tools/bench-vs-sqlite/` | SQLite 对照基准（Rust + rusqlite） |
| `docs/架构设计.md` | 磁盘格式字节级规范 + 里程碑 |
| `docs/实测数据/` | 全部原始 CSV（报数字必须来自这里，禁止手填） |

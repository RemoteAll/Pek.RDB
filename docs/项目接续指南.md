## 1. 项目速览

- 路径：`G:\Code\Rust\Pek.RDB`；crate `pek-rdb`（lib + bin）；远程 `github.com/RemoteAll/Pek.RDB`，分支 `main`。
- 建仓：2026-10-31（空仓库起步，首个提交内容 = 架构设计 + 存储内核 M1）。
- 目标：一体化数据引擎（嵌入/网络双模、文件夹即数据库、Engine + Flux + KV + Pek.RCode Provider）。
- 设计唯一口径：`docs/架构设计.md`。

## 2. 常用命令（构建 / 测试 / 回归）

```powershell
$env:CARGO_TARGET_DIR='D:\cargo-target\pek-rdb'
cargo test                                   # 全部回归
cargo test --test engine                     # 引擎集成测试
cargo test memtable -- --nocapture           # 单模块
cargo clippy --all-targets -- -D warnings
cargo run --bin pek-rdb -- -status           # 状态摘要（M4 起）
```

- 依赖镜像：`.cargo/config.toml`（rsproxy sparse）。
- 交叉验证：`cargo check --target x86_64-unknown-linux-musl`（涉及 Unix 分支时必跑）。

## 4. 目录要点

| 路径 | 说明 |
|---|---|
| `src/codec.rs` / `src/key.rs` | varint、CRC、顺序保持键编码（格式改动需升版本） |
| `src/memtable.rs` | Arena SkipList，排序 `(key ASC, seq DESC)` |
| `src/wal.rs` | 追加日志 + 组提交 + 撕裂尾截断恢复 |
| `src/segment.rs` | 不可变有序段（`.data` + `.idx`，mmap 读 + 稀疏索引 + Bloom + 块缓存） |
| `src/table.rs` / `src/db.rs` | 表 CRUD / 扫描 / flush；数据库目录扫描与全局序号 |
| `docs/架构设计.md` | 磁盘格式字节级规范 + 里程碑 |

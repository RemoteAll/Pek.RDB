- **M0 关键坑（实测暴露）**：`open` 不能把追加点设在「最后一条合法记录末尾」——掉电撕裂时那几个字节已编程过，NOR 只能 1→0，再写会 DeviceFailure。必须把追加点跳到**下一扇区边界**并在扇区尾写 0x00 标记。撕裂尾用例是这条的唯一守门人。

- **M0 压缩 / 环形日志（2026-10-31 已实现）**：分区为环形追加日志（新增 `tail_at[]` 存活区起点，`rawAppend` 尾部放不下就回卷）；`compact(p, scratch≥2扇区)` 按环序搬「后面无同 key 更新」的记录再擦旧扇区；`hasNewer` 用环序距离判定；`get` 按「距 tail 距离」取最新；`scanPartition` 不再遇空扇区 break。实测代价：riscv32 flash 1,610→**1,976B**、thumb 1,370→**1,810B**、TinyStore 32→**40B**、引擎 RAM 88→**96B**。
- **M0 环形日志三个真 bug（都被用例打出来）**：①回卷只判 `slot<tail` 不够，`tail==start` 时回卷覆盖活数据 → 必须 `slot+len<=tail`；②跨扇区无条件写 `at-1=0` 会踩上一条记录 → 仅当 `append%ssize!=0` 才写；③空分区首条写入后未更新 `tail` → 回卷判定失效。**写满/回卷/掉电重开三类用例是这块的唯一守门人。**

- **踩坑（2026-10-31）**：`b.installArtifact(mcu)` 让默认 `zig build` 在宿主链接 mcu-probe（只有 `_start` 没 `main`）→ BUILD=1，而 `zig build test` 看不出来。修：只由 `zig build mcu` 步骤安装。**教训：跑基准前必须先确认 BUILD=0，否则测的是旧二进制。**
- **SPI NOR 适配层（2026-10-31）**：`m0_spi.zig` —— `SpiBus{transceive,cs,delay_ms}` 三原语 → `SpiNor` 实现 BlockDevice（按页切分页编程 + 每段 WREN + RDSR 轮询 BUSY + 扇区 SE、非对齐报错）；`SimNor` 模拟芯片强制「不跨页/只能1→0/需擦除」并统计 violations，主机侧 2 个用例守住（610B 跨页记录 + 擦除粒度/重开）。
- **M0 移植性（2026-10-31 用户「要很方便兼容各种嵌入式系统」）**：接入面 = `read/write/erase/sync` + capacity + sector_size(=擦除粒度)；新增 `m0_diag.selfTest(dev,cfg,scratch)->Report{passed,failed,last_error}`（8 项检查，裸机只判 ok()），并用「撒谎设备（空白读 0x00）」用例证明自检真会报错；新增 `docs/嵌入式移植指南.md`（STM32/ESP-IDF/Zephyr/Arduino/Linux/裸机骨架 + 10 条坑清单 + 检查表）。
- **压缩改成原地游标（2026-10-31，被自检打出的真 bug）**：老实现「把存活记录搬到追加点」，但分区写满时追加点就在末尾 → 必然 NoSpace。改为：读位置从 tail 走一圈、写位置紧跟其后（永不越过读位置），每扇区「读进缓冲→擦除→写存活记录」，完成后 `append_at=写游标`；存活判定用环序窗口 `(abs, append)` 并忽略已处理区。**不需要额外空闲空间**。前面的用例都是「写一些就压缩」所以没暴露，只有「真写满再压缩」才触发。
- **M0 压缩存活索引（2026-10-31）**：`compact` 从 O(记录数×扇区数) 降为 **O(记录数+扇区数)**：`scratch` = `[0,ssize)` 读缓冲 + `[ssize,2ssize)` 查重 + `[2ssize,...)` 索引区（16B/槽：key[8]+dist u32+klen+used，readInt 读写不依赖对齐）。索引槽 <8 或 key_max>8 → 自动退回扫描路径（结果一致）。诊断位 `m0.last_compact_indexed`，用例断言两条路径都跑到且结果逐 key 一致。尺寸未变（TinyStore 40B / flash 1,976B / 1,810B），37 用例全绿。
- **主引擎线：并发 + 超内存（2026-10-31 实测六轮中位）**：并发写（跨表并行，每线程独立 Table，30 万行/线程）1t=1,524,663、2t=2,589,282（1.70×）、4t=3,691,311（2.42×，疑 WAL fsync/磁盘争用）；超内存（200 万行、flush_bytes=8MB、稳定 25 段）写入 1,166,886、点查 645,961（单段 1,393,359 的 46%，25 次 Bloom+块读）、扫描 11,380,144（单段 16.2M 的 70%）、冷重开 24ms。**写类指标本机波动 5–15 倍（后台磁盘/杀毒），按纪律取中位+记 min–max。** 数据 `docs/实测数据/zig-2026-10-31-run{1..6}.csv`。

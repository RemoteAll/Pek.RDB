# 嵌入式移植指南（M0 档）

> 目标：**任何平台，实现 4 个函数就能用 M0**；再加一句 `selfTest()` 就能确认自己接对了。
> 相关设计见 `docs/架构设计.md` §16.5.8 ~ §16.5.11。

## 1. 三分钟接入

M0 只要求实现 `m0.BlockDevice`（`spike-zig/src/m0.zig`）：

```zig
pub const BlockDevice = struct {
    ctx: *anyopaque,                 // 你的设备句柄/状态
    vtable: *const VTable,
    capacity: u32,                   // 总字节数（必须 ≥ "扇区 × 分区数 × 2"）
    sector_size: u32,                // **擦除粒度**（NOR 通常 4096；EEPROM 可取 64）
};

pub const VTable = struct {
    read:  *const fn (ctx: *anyopaque, offset: u32, buf: []u8) Error!void,
    write: *const fn (ctx: *anyopaque, offset: u32, bytes: []const u8) Error!void,
    erase: *const fn (ctx: *anyopaque, offset: u32, len: u32) Error!void,
    sync:  *const fn (ctx: *anyopaque) Error!void,
};
```

然后是存储对象（编译期决定容量/CRC，见 §16.5.9）：

```zig
var store = try m0.StoreType(2, .bitwise).open(dev, .{
    .partitions = 2,      // 2 的幂，≤ 实例化时的 max_parts
    .key_max = 8,
    .value_max = 16,
}, scratch);              // scratch ≥ 1 个扇区（压缩时要 2 个）

try store.put("k", "v", scratch);
var out: [16]u8 = undefined;
if (try store.get("k", &out, scratch)) |v| { /* v */ }
```

**没有堆、没有 OS、没有 mmap、没有线程** —— 全靠调用方给的 `scratch`。

## 2. 四个函数的契约（必须满足，否则语义会坏）

| 函数 | 契约 | 违反后果 |
|---|---|---|
| `read(off, buf)` | `off`/`buf.len` 按扇区对齐；读回原始字节 | 读到错数据 |
| `write(off, bytes)` | NOR 语义：**只能把 1 变 0**；需要能写任意字节区间（内部按页切分由适配层做，若你直接接的是页接口，见 §4） | 覆写已编程字节会失败 |
| `erase(off, len)` | 按**擦除粒度**对齐，擦成 0xFF | 偏移计算错乱 |
| `sync()` | 把写缓存刷到介质；无缓存就空实现 | 掉电丢最近写入 |

**`sector_size` 必须等于芯片的擦除粒度**，不是页大小。M0 保证「一条记录不跨扇区」，所以记录不会跨擦除块。

## 3. 各平台配方（骨架）

### 3.1 STM32（HAL）

```zig
const STM32Nor = struct {
    hspi: *SPI_HandleTypeDef,
    cs_port: *GPIO_TypeDef,
    cs_pin: u16,

    fn cs(ctx: *anyopaque, level: bool) m0.Error!void {
        const self: *STM32Nor = @ptrCast(@alignCast(ctx));
        HAL_GPIO_WritePin(self.cs_port, self.cs_pin, if (level) 0 else 1); // 低有效
    }
    fn transceive(ctx: *anyopaque, tx: []const u8, rx: []u8) m0.Error!void {
        const self: *STM32Nor = @ptrCast(@alignCast(ctx));
        if (tx.len > 0) _ = HAL_SPI_Transmit(self.hspi, @constCast(tx.ptr), @intCast(tx.len), 1000);
        if (rx.len > 0) _ = HAL_SPI_Receive(self.hspi, rx.ptr, @intCast(rx.len), 1000);
    }
    fn delay_ms(ctx: *anyopaque, ms: u32) m0.Error!void { HAL_Delay(ms); }
};
// 然后用 m0_spi.SpiNor{ .bus = ..., .capacity = ..., .sector_size = 4096 }
```

### 3.5 Linux（用户态 / 开发机）

- **spidev**：`SPI_IOC_MESSAGE` 一次事务里做完 `cmd+addr+data`，`sector_size` 取芯片 4KB。
- **MTD**：直接 `MEMERASE` / `read` / `write`。
- **开发调试**：用 `m0.RamDevice`（内存盘）或写个文件映射版（注意文件不满足「只能 1→0」，仅用于逻辑验证）。

### 3.6 自写裸机 SPI

只要保证三件事：CS 低 → 连续时钟 → CS 高；命令与数据在同一 CS 事务里。`m0_spi.SpiNor` 已按此组织：
`WREN(0x06)` / `RDSR(0x05)` / `READ(0x03)` / `PP(0x02)` / `SE(0x20)`。

## 4. 如果你手上只有「页接口」（没有字节写）

若底层只提供「写一页（256B，页内偏移 0）」，有两种做法：

1. **推荐**：把 `sector_size` 设为页大小（如 256），让 M0 在页粒度上分配；擦除函数改成「写 0xFF 整页」。
2. 或者写一个「读-改-写」包装：读整页 → 合并 → 写整页。代价是写放大，建议只在 EEPROM 上用。

## 5. 上电自检（把「接对了吗」变成可执行的事）

```zig
const m0_diag = @import("m0_diag.zig");

var scratch: [1024]u8 = undefined;
const r = m0_diag.selfTest(myDev, .{ .partitions = 2 }, &scratch);
// 裸机上打印不了字符串也没关系：判 r.ok() / r.failed / r.last_error 即可
```

`selfTest` 会检查 8 项：参数合法性、空白=0xFF、擦除、写入回读、覆盖写、删除、**重新 open 后语义仍对**、
写满 → 压缩 → 继续写。**它会破坏被测试区域的数据**，只在空白/专用区或产线首启时跑。

回归里还有一个「撒谎设备」用例（空白读返回 0x00）用来证明自检**真的能抓出不合规实现**，
不是永远绿。

## 6. 常见坑清单

- [ ] **页编程跨页**：一条 PP 命令不能跨越 256B 页边界（`m0_spi` 已按页切分；自己接要自己切）
- [ ] **擦除粒度 ≠ 写粒度**：`sector_size` 必须填擦除粒度
- [ ] **CS 时序**：命令+地址+数据必须在同一次 CS 低电平期间
- [ ] **BUSY 轮询**：擦除典型 30~300ms，写完必须等 BUSY 清零（`m0_spi` 有超时）
- [ ] **写保护位**：BP 位没解除会导致写入静默失败（读回还是 0xFF）
- [ ] **4 字节地址**：容量 > 16MB 的芯片要用 `0x13/0x0C/0x21` 等 4 字节命令
- [ ] **XIP 冲突**：芯片正在被 CPU 执行代码时不能写
- [ ] **缓存一致性**：有 D-Cache 的 MCU（M7）写后读要清缓存，否则读到旧数据
- [ ] **上电时间**：部分芯片上电后需等待 `tPUW`（如 5ms）才能收命令
- [ ] **容量与分区**：`capacity / partitions` 必须 ≥ 2 个扇区，否则 `open` 报 `BadPartitions`

## 7. 移植检查表

1. 实现 4 个函数 + `capacity` + `sector_size`（=擦除粒度）；
2. `m0_diag.selfTest()` 全绿（`r.ok()` 为 true，`r.failed == 0`）；
3. 断电重启后数据仍在（拔电试验，至少 20 次）；
4. 写满后 `compactAll` 能继续写；
5. `zig build sizes` / `tools/elf-size.py` 记录 flash 与静态 RAM，留证到 `docs/实测数据/`。

## 说明

- `scan_refs` / `scan` 为“仅取 key、零拷贝”，`scan` / `scan_v` 为“取值并解码”。
- `recover` 单位为毫秒，越低越好；其余为越高越好。
- SQLite 的 `put`（逐行 autocommit）在 Windows + WAL 下波动极大（本轮 min–max 已列出），比较时以中位为准。
